# Top Five Destinations List - SNHU Travel

Java Swing application that fulfills User Story 1 for the SNHU Travel project.

## Features
- Ordered list of the top five destinations (most popular first)
- Each item shows destination name, one-sentence description, and image
- Text includes reference to top-selling travel package
- Blue color scheme customization
- Name label: Megan Brackat
- Clear comments explaining changes

## How to Run in Eclipse
1. Create a new Java project.
2. Copy `src/TopFiveDestinationList.java` into the src folder.
3. Create a folder named `resources` (or place images in the default package resources).
4. Copy the `.jpg` files into the resources folder so they are on the classpath.
5. Right-click the project → Export → Runnable JAR file.
6. Select the main class `TopFiveDestinationList`.

## Notes
- Images are scaled for the list view.
